# Terraform Starter / Starter Terraform

## Overview / Visão geral

**EN:** Minimal Terraform layout with a null_resource example and an AWS S3 bucket skeleton (commented / placeholder).

**PT:** Layout mínimo Terraform com exemplo `null_resource` e esqueleto de bucket S3 AWS (comentado / placeholder).


## Usage / Uso

```bash

terraform plan

```

**EN:** Do not commit secrets or real cloud credentials.
